Política de Privacidad y Tratamiento de Datos

En LUXPROC INNOVACIÓN Y TECNOLOGÍA S.A.C. nos comprometemos con la total transparencia, seguridad y privacidad de la información de nuestros usuarios y clientes empresariales. Esta política detalla de manera estática y pública nuestras prácticas de tratamiento de datos personales conforme a la Ley N° 29733 de la República del Perú y los estándares internacionales de seguridad.

Compromiso de Privacidad y Requisitos de Google OAuth (Google API Services User Data Policy)

1. Qué datos recopilamos
Únicamente los datos básicos de perfil proporcionados al iniciar sesión mediante Google: nombre completo y dirección de correo electrónico institucional o personal.
2. Para qué los usamos
Exclusivamente para gestionar el acceso seguro y autenticado a los portales de ingeniería de LUXPROC, agendar reuniones técnicas y enviar notificaciones operativas.
3. Protección y Privacidad
No compartimos, no vendemos ni transferimos datos a terceros bajo ninguna circunstancia. Cumplimos con los requisitos de Uso Limitado de Google.

2. Datos Recopilados y Procedencia

Cuando el usuario interactúa con nuestra plataforma o decide autenticarse mediante Google OAuth, recopilamos únicamente los datos indispensables autorizados expresamente en la pantalla de consentimiento de Google:

  • Nombre y Apellido: Utilizados exclusivamente para identificar al usuario en las sesiones técnicas y dirigir la correspondencia formal.
  • Dirección de Correo Electrónico: Empleada como identificador único de cuenta, para confirmación de servicios, envío de expedientes y enlace de sesiones de videoconferencia (Google Meet).
  • Foto de perfil pública (Avatar): Proporcionada de forma predeterminada por la cuenta de Google con fines de representación visual dentro del entorno web.
Aviso de seguridad sobre credenciales: LUXPROC jamás solicita, tiene acceso ni almacena contraseñas de cuentas de Google o de servicios de terceros. Toda autenticación se realiza de manera delegada y cifrada mediante tokens criptográficos estándar OAuth 2.0.

3. Finalidad del Uso de los Datos

Los datos personales solicitados se tratan estrictamente para los siguientes fines legítimos:

  • Gestionar el acceso seguro a los módulos corporativos, cotizaciones de peritaje eléctrico (CIP N° 278034) y soluciones de software ERP/CRM.
  • Coordinar y calendarizar citas técnicas en Google Calendar y generar enlaces seguros de reunión en Google Meet.
  • Enviar reportes de soporte, seguimiento de requerimientos de ingeniería y expedientes técnicos autorizados.
  • Garantizar la seguridad operativa de la infraestructura, previniendo suplantaciones de identidad o accesos no autorizados.

4. No Comercialización ni Cesión a Terceros

LUXPROC mantiene una política estricta de protección de datos:

  • No venta de datos: No vendemos, alquilamos ni comercializamos datos personales a anunciantes, brokers de datos ni plataformas publicitarias externas.
  • No cesión a terceros: Los datos no se transfieren a empresas no vinculadas con la prestación técnica del servicio.
  • No entrenamiento de modelos externos: Los datos de usuario y el contenido de las integraciones de Google no se emplean para entrenar modelos generalistas de inteligencia artificial de terceros.

5. Cumplimiento de la Política de Datos de Usuario de las API de Google

El uso de la información recibida a través de las APIs de Google por parte de LUXPROC cumple estrictamente con la Política de Datos de Usuario de los Servicios de API de Google (Google API Services User Data Policy), incluidos los requisitos de Uso Limitado (Limited Use Requirements):

"El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google por parte de LUXPROC se adherirán a la Política de Datos de Usuario de los Servicios de las API de Google, incluidos los requisitos de Uso Limitado."

6. Retención, Eliminación y Revocación de Acceso

Los datos personales se conservan únicamente durante el tiempo necesario para la prestación del servicio acordado o hasta que el usuario solicite su eliminación.

  • Revocación directa: El usuario puede revocar en cualquier momento el acceso concedido a la aplicación desde su propia cuenta de Google en: https://myaccount.google.com/permissions.
  • Solicitud de borrado: Puede solicitar la supresión total de sus registros enviando un correo a luxproc.11@gmail.com, la cual se procesará en un plazo máximo de 48 horas hábiles.

7. Seguridad y Cifrado

Implementamos protocolos de seguridad informática avanzados para resguardar la confidencialidad de la información:

  • Cifrado SSL/TLS 1.3 de extremo a extremo en todas las comunicaciones web HTTPS bajo el dominio verificado luxproc.com.
  • Protección de bases de datos mediante controles de acceso restringido y políticas estrictas de menor privilegio (Least Privilege Access).
  • Monitoreo continuo de incidentes de seguridad y respaldos automatizados.

8. Derechos ARCO (Ley N° 29733 del Perú)

Conforme a la Ley de Protección de Datos Personales del Perú (Ley N° 29733) y su Reglamento, usted puede ejercer en cualquier momento sus derechos de:

  • Acceso: Conocer qué información personal mantenemos en nuestros registros.
  • Rectificación: Solicitar la corrección de datos inexactos o incompletos.
  • Cancelación: Solicitar la supresión o eliminación de sus datos de nuestras bases.
  • Oposición: Oponerse al tratamiento de sus datos para fines específicos.
